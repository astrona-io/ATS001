# Rolling Updates And Availability

This module develops rolling Updates And Availability. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Identify changes that create Deployment revisions.
- Calculate surge and unavailability limits.
- Explain readiness and capacity effects on rollout.
- Distinguish reported progress failure from automatic recovery.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
