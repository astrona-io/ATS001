# Reusable Kustomize Composition

This module develops reusable Kustomize Composition. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Explain a base, overlay and resource composition.
- Trace naming and namespace transformations.
- Explain generated configuration references and hashes.
- Review final selectors and supported API definitions.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
