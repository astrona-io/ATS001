# Canary Exposure And Promotion

This module develops canary Exposure And Promotion. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Explain shared Service selection for stable and canary Pods.
- Estimate exposure from ready endpoints with stated limits.
- Choose version-specific promotion evidence.
- Distinguish withdrawal from full release promotion.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
