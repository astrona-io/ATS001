# A Prepared Blue-Green Switch

This module develops a Prepared Blue-Green Switch. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Explain Service selection across two versions.
- Verify readiness, capacity and backend ports.
- Distinguish a traffic switch from a data migration.
- Evaluate the conditions for safe traffic rollback.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
