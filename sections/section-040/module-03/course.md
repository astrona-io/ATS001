# Existing Charts And Effective Values

This module develops existing Charts And Effective Values. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Distinguish chart, application and release identities.
- Trace value precedence into rendered fields.
- Review chart dependencies and resource requirements.
- Separate rendering, admission and application health.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
