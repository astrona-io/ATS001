# Summary

Charts package resource templates and supporting inputs. Values influence the fields that templates actually use, and release identity distinguishes an installed instance from the package itself.

Rendered objects expose the intended resources but do not guarantee API acceptance or useful application behavior. Correct installation requires suitable images, permissions, storage, routing and configuration in the chosen environment.
